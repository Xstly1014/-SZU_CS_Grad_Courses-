深圳大学计算机技术专业研究生课程的学习资料归档，涵盖 **研一上 / 研一下** 两个学期的课程课件、平时作业、课程论文与实验代码，可供选课参考与复习使用。

## 目录结构

```text
SZU_CS_Grad_Courses
├── 研一上
│   ├── 专业英语            # 课件、期末表格模板
│   ├── 基础英语            # 课程讲义（Lecture 1-6）、笔记与作业
│   ├── 复杂系统与复杂网络   # 平时作业、期末论文与代码
│   ├── 数据挖掘            # 课件（w1-w10）、小组综述与期末大作业
│   ├── 新时代中特          # 期末论文
│   ├── 算法设计与分析       # 章节课件、参考答案、实验与试卷
│   ├── 计算机前沿技术       # 论文复现报告（LaTeX 源码）、汇报与实验代码
│   └── 论文写作指导        # 写作讲义（科技论文/学位论文）、期末论文
└── 研一下
    ├── 优化理论与应用       # 课程汇报 PPT、课程论文
    ├── 工程伦理            # 平时作业、期末大作业
    ├── 机器学习            # 课堂汇报、课程论文与项目代码
    ├── 模式识别            # 四次作业（含代码）、开卷考试课堂资料
    └── 自然辩证法概论       # 课程论文及相关表格
```

各课程目录下按 `课程文件`（教师提供的课件与模板）和 `作业`（个人完成的作业、论文与代码）分类存放。

## 课程概览

### 研一上（2024-2025 学年第一学期）

| 课程 | 主要内容 | 考核方式 |
| --- | --- | --- |
| 专业英语 | 科学论文写作、国际学术会议课件 | 个人综述 + 小组 PPT 汇报 + 课堂翻译测验 |
| 基础英语 | 综合英语讲义（教育、健康、全球化等主题） | 随堂汇报 + 个人介绍 |
| 复杂系统与复杂网络 | 复杂网络中心性、节点重要性、LeaderRank 等算法实践 | 考勤 + 平时作业 + 期末论文（含代码） |
| 数据挖掘 | 数据思维、机器学习模型回顾、聚类、模型验证 | 小组综述 + 小组 PPT + 期末大作业 |
| 新时代中特 | — | 考勤 + 期末论文 |
| 算法设计与分析 | 分治、贪心、动态规划、回溯、图论、NP 问题等章节课件与参考答案 | 实验报告（含代码）+ 附加作业 + 闭卷考试 |
| 计算机前沿技术 | 论文复现（自适应预设时间控制） | 复现报告（LaTeX）+ 汇报 PPT + 实验代码 |
| 论文写作指导 | 科技论文结构、绪论与研究方法写作要点 | 期末论文 + 结课开卷考试 |

### 研一下（2024-2025 学年第二学期）

| 课程 | 主要内容 | 考核方式 |
| --- | --- | --- |
| 优化理论与应用 | 基于优化理论的网络重建方法研究 | 课程汇报 + 课程论文 |
| 工程伦理 | AI 时代技术伦理困境、经典工程伦理案例 | 平时作业 + 期末大作业 |
| 机器学习 | 基于线性回归分类的人脸识别方法（LRC） | 课堂汇报 + 课程论文（含代码） |
| 模式识别 | 贝叶斯推断、SVM、特征降维、神经网络、ViT、扩散模型 | 四次作业（含代码）+ 开卷考试 |
| 自然辩证法概论 | — | 课程论文 |

## 使用说明

```bash
git clone https://github.com/Xstly1014/-SZU_CS_Grad_Courses-.git
```

也可在仓库页面点击 **Code → Download ZIP** 直接下载。资料以文档（PDF / Word / PPT）为主，代码集中在对应课程的 `作业` 目录中，解压后即可查看。
